### Method limitations
Eligibility counts refer to a processed 1m feature snapshot, not valid entry; native/book missing reasons tracked. Market regime is a separate end-of-window observation; no late features used as earlier evidence. R11.1 current state is held in RAM until cycle finalization; restart may lose the unfinished cycle, not committed history. Missed-event coverage counts exact cycle eligibility (15 windows), not guaranteed quote coverage. READY comparisons use decision timestamp <= event close and a bounded lookback 15m before baseline window. Do not claim independent events or actual lead to movement onset. R11 v1 and v2 use same upstream feed after upgrade but different readiness logic. Native 15m context and early pressure not validated yet. Tests/CI and actual export evaluation required; no waiting for research to improve ordinary operations.
