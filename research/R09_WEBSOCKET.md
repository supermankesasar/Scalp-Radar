# R09 hybrid public market streams
Source: https://developers.binance.com/en/docs/products/derivatives-trading-usds-futures/websocket-market-streams/Important-WebSocket-Change-Notice
One launcher, main, no account keys, no orders, no AI. Routed /market klines 1m/5m/15m/1h/4h, aggTrade, !ticker@arr, !forceOrder@arr; /public depth5@500ms. Connections split into bounded groups; reconnect exponential backoff, heartbeat, planned renewal. Cache only returns contiguous closed bars through expected latest close; REST seeds and recovers gaps. Existing scanner skips inter-batch wait only on fully cached batches, reevaluates on new 5m boundary, maintains existing ranking and protections. Initial bootstrap and REST fallback can still be slow. REST archive still supplies OI/positioning/funding, not streaming OI. Live R08 CORE stays default; new 1m rules are independent forward research, not live trade alerts.
Minute ledger records features and candidates, including EMA9/10/14 price crosses, RVOL control, aggressive flow, big aggregate print, partial-book imbalance, depth vacuum proxy, liquidation burst proxy, absorption, acceleration, multi-micro. Each has separate outcomes 15/30/60m confirmed by 1m closes, same .65%/.4% floors but ATR1m, so compare horizons and coverage carefully. Source close baseline is not a fill. Candidate receipt latency stored and 15s cap; no silent stale trades/depth. Big print is aggregate trade not whale identity. Liquidation stream is sampled exchange reporting, not all liquidations. Depth is top 5 snapshot, not full reconstructed book or proof of cancellations. No per-tick raw history; minute summaries and raw closed candles are persisted, reducing disk. Missing coverage excludes affected hypotheses; zero observed liquidation is not proof none occurred. No raw aggTrade recovery; reconnect creates gaps rather than inventing data. Public feed all symbols can be CPU/network intensive; monitor /api/websocket for lag, gaps, connections and REST fallback. 1m research is once per closed minute, not tick-level signal emission. Prior R08 weights are unchanged. No validated profitability.
