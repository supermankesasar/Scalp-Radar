## Remaining R06
Top trader account/position ratios, historical order book, aggregate trades/large trade analysis, liquidation stream not included. Global ratio counts accounts, not actual net contracts/notional; OI aggregate cannot identify new long versus short. Price+OI+flow hypotheses do not establish whale identity. Last realized funding is not current predicted funding. Need point-in-time live collection and independent forward windows.
 
## Architecture
Research rule modules in research/filters; frozen generated bundle solely for tool execution. Staging Python scanner modular rules in filters/, registry composes legacy score and independent EMA challenger tags; no scoring promotion. research_history.py additive central SQLite tables shared with existing signals DB; all detected candidates tracked independently of top five, with 15/30/60m outcome rows at 5m/15m confirmation. Archive importer combines prior and current immutable JSON batches in same DB with run IDs. Import not run on production. Branch main not changed. Staging code requires tests and live verification before deploy.
